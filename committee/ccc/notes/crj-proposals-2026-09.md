## c03 classification

C03 is lecture/composition, lecture/counseling, lecture/case study: 1 class hour per unit, K-factor 1.0, normal class size 35. C02 (lecture and/or discussion) has the same hours and K-factor with a normal class size of 50. A C02 to C03 change lowers the normal cap at the same WTU. Source: [CSUEB course classification table](https://www.csueastbay.edu/aps/academic-programs/curriculum-development-new/cpm/class-table.html).
