# forms

Word forms and memos for the Department of Music, built from the house-style template in [`conventions/templates/`](../../conventions/templates/).

- [equipment-office-student-assistant-agreement.docx](equipment-office-student-assistant-agreement.docx): the agreement an equipment office student assistant signs at hire.
- [key-1838-authorization-memo.docx](key-1838-authorization-memo.docx): key authorization for MB 1838.
- [fast-application.docx](fast-application.docx): the FAST 4+1 B.A./M.A. application packet the Graduate Coordinator sends to students, with eligibility, deadlines, materials, submission by email, and the application form.
