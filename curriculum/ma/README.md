# M.A. in Music

Program documentation for the M.A. in Music, catalog 2027–2028. Both files follow the EEC templates. Draft for faculty review.

- `ma-music-curriculum-map.docx`: curriculum map of the five PLOs against the required courses and the comprehensive examination, with I/D/M levels and assessment points.
- `ma-music-long-term-assessment-plan.docx`: long-term program curriculum assessment plan, one row per PLO, assessed 2027–2028 through 2031–2032.
