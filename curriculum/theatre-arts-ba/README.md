# B.A. in Theatre Arts

Program documentation for the B.A. in Theatre Arts, catalog 2027–2028, for the program revision in Curriculog. Both files follow the EEC templates. Draft for faculty review.

- `theatre-arts-ba-curriculum-map.docx`: curriculum map of the four PLOs against the core courses and the major electives, with I/D/M levels and assessment points.
- `theatre-arts-ba-long-term-assessment-plan.docx`: long-term program curriculum assessment plan, one row per PLO, assessed 2027–2028 through 2030–2031.
